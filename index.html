FAQ

The client_data module type is used primarily for client-side scripts, client-bound modules, or specialized UI scripts. While standard resource packs use resources for textures, models, and audio, client_data is specified when delivering client-bound script execution or custom client-side logic to the game engine.
No. Subpacks and Pack Settings are only supported by Resource Packs (resources) and select Behavior Packs (data). World templates (world_template) and skin packs (skin_pack) rely on strict, predefined structures (such as fixed world save files or skins.json) and do not support in-game manifest settings or subpack folders.
format_version 3 introduces support for newer and more advanced pack features like Pack Settings (toggles and dropdowns in the UI) and advanced Subpacks. Using version 3 typically requires a higher min_engine_version (usually 1.26.0 or newer) to function correctly in-game. Version 2 is the legacy format used for simpler packs.
The memory_performance_tier property is used within subpacks to define the hardware requirements for that specific subpack configuration. Higher tiers will automatically disable the subpack on lower-end devices (like older mobile phones) with limited RAM, which prevents the game from crashing due to high-resolution textures or heavy models. 0 is the default/lowest tier.
Capabilities (such as pbr, raytraced, or experimental_custom_ui) tell the Minecraft engine that your pack requires specific rendering engines or experimental toggles to function. For example, adding pbr enables Physically Based Rendering for Deferred Graphics.
A UUID (Universally Unique Identifier) is a random string of characters that Minecraft uses to identify your pack. Every pack and module must have a completely unique UUID. If two packs share the same UUID, Minecraft will think they are the same pack and will fail to load one of them. This generator automatically creates secure, randomized UUIDs for you!
Yes! Subpacks allow you to bundle multiple variations of your pack into one file. Players will see a gear icon next to your pack in-game, allowing them to choose between different resolutions, UI styles, or features by moving a slider.
Pack Settings allow you to create interactive UI elements like dropdown menus and toggles within your pack's configuration screen. When set up correctly in format_version 3, these settings can map to specific behavior pack variables, allowing players to customize exactly how your add-on behaves without needing separate subpacks.

About

mcpack generator

A rapid, web-based tool designed to easily generate valid manifest.json files for your Minecraft Bedrock Add-Ons, without requiring you to manually write a single line of JSON code.

It supports all modern pack types including Resource Packs, Behavior Packs, Skin Packs, World Templates, and Client Data, alongside complex configurations like Pack Settings and Subpacks.
